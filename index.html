What this list is

O que é esta lista

Awesome Open Source Research Tools tracks open source software that supports any part of a rigorous, systematic research project. If a tool is open source and helps with collecting data, managing it, analyzing it (qualitatively or quantitatively), keeping the work reproducible, writing it up, or reviewing existing literature, it belongs here — regardless of discipline. Social sciences, natural sciences, health sciences, digital humanities: all welcome, as long as the software itself is open source. Awesome Open Source Research Tools reúne software de código aberto que apoia qualquer parte de um projeto de pesquisa rigoroso e sistemático. Se uma ferramenta é de código aberto e ajuda a coletar dados, organizá-los, analisá-los (qualitativa ou quantitativamente), manter o trabalho reprodutível, escrevê-lo ou revisar a literatura existente, ela tem lugar aqui — independentemente da disciplina. Ciências sociais, ciências naturais, ciências da saúde, humanidades digitais: todas bem-vindas, desde que o software em si seja de código aberto.

It lives as a GitHub "awesome list": a single, community-maintained README, released under CC0 so anyone can reuse, fork, or republish it freely. This page is a friendlier front door to that same list. Ela existe como uma "awesome list" do GitHub: um único README mantido pela comunidade, publicado sob CC0 para que qualquer pessoa possa reutilizar, fazer fork ou republicar livremente. Esta página é uma porta de entrada mais amigável para essa mesma lista.

brverse (Ipea) ↗

Curated directory and ecosystem of open source R packages maintained by the Institute for Applied Economic Research (Ipea) for programmatic, reproducible access to official Brazilian socioeconomic, census, and spatial data, strengthening national data sovereignty.

Ecossistema e diretório curado de pacotes R mantidos pelo Instituto de Pesquisa Econômica Aplicada (Ipea) para acesso programático e reprodutível a dados públicos oficiais brasileiros (socioeconômicos, censitários e espaciais), fortalecendo a soberania nacional de dados.

How to contribute

Como contribuir

Additions are evaluated against an objective checklist, not personal preference. A tool is generally accepted if it is: As adições são avaliadas por um checklist objetivo, não por preferência pessoal. Uma ferramenta é geralmente aceita se for:

1
Open sourceCódigo aberto

Released under a recognized open source or free-culture license (not "source available" or freemium).

Publicada sob uma licença de código aberto ou cultura livre reconhecida (não "source available" nem freemium).

2
Actively maintainedAtivamente mantida

Shows recent commits, releases, or maintainer activity — not an abandoned repository.

Apresenta commits, releases ou atividade recente de mantenedores — não é um repositório abandonado.

3
DocumentedDocumentada

Has at least minimal documentation explaining what it does and how to use it.

Tem ao menos documentação mínima explicando o que faz e como usar.

4
Non-redundantNão redundante

Adds something the list doesn't already cover, or is clearly a stronger fit than what's listed.

Acrescenta algo que a lista ainda não cobre, ou é claramente mais adequada do que o que já está listado.

Read the full contribution guidelines and open a pull request against README.md (and, where possible, README.pt-BR.md). Leia as diretrizes de contribuição completas e abra um pull request no README.md (e, quando possível, no README.pt-BR.md).
